# ☕ Cafe-Cage

### Full Stack Cafe & Grocery Shopping Web Application

Cafe-Cage is a full-stack web application developed using the MERN Stack as a TYBCA academic project. It provides product browsing, shopping cart, order management, customer authentication and seller management features.

## 🚀 Features

- User Registration and Login
- Product Browsing and Categories
- Shopping Cart Management
- Address Management
- Order Management
- Seller Dashboard
- Product Management
- Sales Growth Dashboard
- Table Reservations

## 🛠️ Technology Stack

- **Frontend:** React.js, Vite, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Image Storage:** Cloudinary

## 📁 Project Structure

- `client/` – React frontend
- `server/` – Node.js and Express backend

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ajay12aj/Cafe-Cage.git
   ```

2. Install frontend dependencies:
   ```bash
   cd client
   npm install
   ```

3. Install backend dependencies:
   ```bash
   cd ../server
   npm install
   ```

4. Configure your environment variables using `server/.env.example`.

5. Start the backend and frontend using their respective start scripts.
